Présentation du jeu

Elden Ring est un jeu vidéo de type action-RPG développé par FromSoftware.

Le joueur incarne un Sans-éclat qui doit explorer les Terres Intermédiaires.

Le monde est rempli de secrets, d'ennemis, de personnages et de boss.

Le gameplay

⚔️ Les combats

Les combats sont très importants dans Elden Ring. Le joueur peut utiliser différentes armes et compétences.

✨ La magie

Il est également possible d'utiliser différents sorts et incantations.

🐎 L'exploration

Le joueur peut explorer un immense monde ouvert à pied ou avec sa monture.

Les boss

Elden Ring possède de nombreux boss qui rendent les combats particulièrement importants dans le jeu.

Malenia

Malenia est connue comme la Lame de Miquella.

Starscourge Radahn

Radahn est un puissant général connu comme le Fléau des étoiles.

Godfrey

Godfrey est le Premier Seigneur d'Elden.
